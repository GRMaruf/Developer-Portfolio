01 — About

A backend-leaning generalist who genuinely likes the unglamorous parts.

I'm a Junior Django Developer based in Dhaka, Bangladesh. I started writing Python in university and never quite stopped — what began as scripts to automate boring classwork turned into a proper interest in web architecture, database design, and clean API contracts.

I've spent the last year and a half building production-adjacent projects with Django and Django REST Framework — a quiz portal, a resume builder, and a small job board. Along the way I've learned that the hard parts are rarely the framework; they're the naming, the data model, the edge cases, the tests.

I'm currently looking for a Junior Backend role where I can be useful, learn from senior engineers, and slowly earn ownership of a slice of the system. Remote, hybrid, or on-site — all fine. I just want to write code that outlives the sprint.
